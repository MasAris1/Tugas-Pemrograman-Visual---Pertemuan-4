1. DESKRIPSI APLIKASI
   Motor Olla adalah aplikasi web interaktif kalkulator kredit simulasi 
   cicilan motor dengan skema bunga flat resmi untuk pasar Indonesia. 
   Aplikasi ini dirancang menggunakan arsitektur Desktop Split Screen 
   (Katalog di kiri, Kalkulator di kanan), responsif penuh untuk tablet 
   dan smartphone, serta foto produk asli beresolusi tinggi dengan rasio 1:1.

2. KEPATUHAN STRUKTUR KONTROL AKADEMIK (PERTEMUAN 4)

   a. Minimal 2 Input Visual:
      1. Input Nominal Uang Muka / DP (#inputDP) dengan auto-separator ribuan 
         dan prefix Rp.
      2. Input Jangka Waktu Kredit / Tenor (Radio button: 11, 23, 29, 35 Bulan).
      - Dilengkapi tombol pintas persentase Quick DP (20%, 30%, 40%).

   b. Minimal 1 Tombol Aksi:
      - Tombol "Hitung Simulasi Cicilan" (#btnHitung).

   c. Validasi Input Numerik (Ekuivalen TryParse):
      - Fungsi: tryParseDP(rawDP, hargaOTR, dpMinPersen)
      - Pengujian 1: Cek kekosongan input (rawDP === "").
      - Pengujian 2: Cek numerik murni (!isNaN(parsedValue)).
      - Pengujian 3: Cek batas nilai negatif (parsedValue < 0).
      - Pengujian 4: Cek batas minimum DP (DP < OTR * dpMinPersen / 100).
      - Pengujian 5: Cek batas maksimum (DP >= OTR).
      - Hasil validasi menghasilkan objek { isValid, nominal, pesan }. 
        Jika invalid, eksekusi dihentikan dengan return dan menampilkan pesan 
        error merah di bawah input tanpa menimbulkan runtime error / NaN.

   d. Logika Percabangan (if - else):
      - Fungsi: tentukanSukuBungaFlat(tenorBulan)
      - Menentukan besaran suku bunga flat per tahun berdasarkan jangka waktu kredit:
        * tenor <= 12 Bulan : 7.0% per tahun (0.070) -> misal: tenor 11 bulan
        * tenor <= 24 Bulan : 8.0% per tahun (0.080) -> misal: tenor 23 bulan
        * tenor <= 36 Bulan : 9.5% per tahun (0.095) -> misal: tenor 29 & 35 bulan
        * tenor > 36 Bulan  : 10.0% per tahun (0.100)

   e. Rumus Finansial Perhitungan Kredit Flat:
      - Pokok Pinjaman   = Harga OTR - Nominal DP
      - Tenor Tahun      = Tenor Bulan / 12
      - Total Bunga      = Pokok Pinjaman * Suku Bunga Flat * Tenor Tahun
      - Total Utang      = Pokok Pinjaman + Total Bunga
      - Angsuran Bulanan = Total Utang / Tenor Bulan

   f. Logika Perulangan (for Loop):
      - Fungsi: renderJadwalAngsuran(simulasi)
      - Loop for dijalankan dari bulan = 1 sampai bulan = tenorBulan:
        for (let bulan = 1; bulan <= tenorBulan; bulan++) {
          sisaPokok = Math.max(0, sisaPokok - pokokPerBulan);
          if (bulan === tenorBulan) sisaPokok = 0;
          // Render elemen baris <tr> ke dalam <tbody>
        }
      - Menghasilkan rincian angsuran pokok, bunga per bulan, total cicilan, 
        dan sisa pinjaman yang menurun bertahap hingga lunas (Rp 0) di akhir tenor.

3. TATA LETAK JADWAL ANGSURAN: MODAL POP-UP DIALOG (OPSI C)
   Sesuai pilihan pengguna (Opsi C), jadwal angsuran disajikan dalam
   bentuk Modal Pop-up Dialog Interaktif (#scheduleModal):
   - Di Desktop/Web: Pengguna dapat menekan tombol "Buka Jadwal Lengkap"
     pada kartu ringkasan estimasi angsuran untuk menampilkan popup jadwal
     tanpa terpotong batas viewport sidebar.
   - Di Mobile: Tombol "Jadwal" di Sticky Bottom Bar langsung membuka modal
     secara instan tanpa mengharuskan pengguna melakukan scroll panjang.
   - Fitur Modal:
     * Header informatif lengkap dengan nama unit motor dan durasi tenor.
     * Summary pill banner: cicilan per bulan, pokok, dan total pinjaman.
     * Container tabel responsif dengan horizontal dan vertical scrolling.
     * Aksesibilitas: Tombol tutup (X), tombol footer "Tutup Rincian",
       klik di area backdrop, serta penekanan tombol Escape pada keyboard.

5. FITUR RESPONSIFITAS & PERBAIKAN MOBILE CUTOFF
   - Root Overflow Prevention: Mengeliminasi horizontal blowout dengan
     `max-width: 100vw; overflow-x: hidden;` pada root document.
   - Header 100% Full-Width: Menjamin judul, logo, dan badge resmi tidak terpotong
     pada viewport smartphone berukuran kecil (360px - 412px).
   - Mobile Sticky Bar: Ditempatkan tetap di bawah layar (fixed bottom) selebar 100%
     viewport dengan bantalan padding-bottom pada body agar konten tidak tertutup.
   - Responsif Antar Layar:
     * Desktop (>= 1024px): Split Screen dua kolom.
     * Tablet (768px - 1023px): Two-column catalog grid.
     * Mobile (< 768px): Single card 1:1 catalog dengan horizontal category chips.
